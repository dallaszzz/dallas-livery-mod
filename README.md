# Dallas Livery Mod for Low Level Hunters

This mod allows you to use custom textures for player helicopters in the Low Level Hunters demo. The mod is currently very unfinished but should function to some degree.

An important note is that the base game models were not UV mapped with non-generic textures in mind so this mod replaces base game models with fixed models that have proper uv mapping.

Installing requires building the project and copy pasting the results from the bin folder into your BepInEx plugins folder. 

The code requires the Assembly-CSharp.dll file from the game to be pasted into the lib folder within the repo (Im not sure if this is required for building or just IDE features).
